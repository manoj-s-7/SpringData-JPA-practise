### Hospital-Management-System-API

This project is a Hospital Management System API built using Spring Boot as part of my backend development learning journey. It focuses on implementing core concepts like RESTful API design, layered architecture, and basic security. The application includes features such as managing patients, doctors, and appointments. This project is still under development, and I am continuously improving it by adding new features and enhancing existing functionalities as I learn more about Spring Boot and backend systems.
